# Security, AI Risk and Validation

- Entra ID authentication and project-scoped RBAC.
- Separate protocol author, screener, extractor, clinical reviewer, and approver roles.
- Immutable search strategy versions and source snapshots.
- Claim-level citations and evidence-set hashes.
- Prompt injection isolation: source text is untrusted data, never instructions.
- No autonomous exclusion, appraisal approval, clinical conclusion, or report release.
- Golden-set validation for screening recall, extraction accuracy, citation correctness, and contradiction detection.
- IQ/OQ/PQ evidence, requirements traceability, backup/restore, penetration testing, and model-change regression testing.
